# Getting started

## Installation

You need **Python 3.10+**. No other tools are required.

```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.lock
```

`requirements.lock` pins the exact versions everyone else uses. For the
latest compatible versions instead, use `pip install -r requirements.txt`.

Two extras are available:

```bash
pip install .[numba]      # JIT-compiled backend for the ABCD/S-matrix solvers
pip install .[dashboard]  # interactive Streamlit S-parameter viewer
```

## Quickstart

```python
from simulation import SimulationConfig, Simulation
from models import JTLDiscrete

cfg = SimulationConfig(
    ncell=500,
    omega_pump=6.8 * 2 * 3.14159,
    epsilon=0.05,
)

sim = Simulation(JTLDiscrete, cfg)
S = sim.get_s_matrix()
sim.plot_s_parameters([(1, 1), (3, 1)])
```

- {py:class}`~simulation.SimulationConfig` holds every physical and numerical
  parameter (cell count, pump frequency, modulation depth, disorder, ...);
  every field has a default, so `SimulationConfig()` alone is valid.
- {py:class}`~simulation.Simulation` builds the unit-cell chain from a cell
  factory (e.g. {py:class}`~models.JTLDiscrete`,
  {py:class}`~models.JTLDiscreteMultiPump`), cascades it into an S-matrix,
  and exposes plotting helpers.

## Numerical backends

The ABCD-to-S conversion and Redheffer-star cascade run on a pluggable
backend (see {py:mod}`backends`). Select one explicitly:

```python
sim = Simulation(JTLDiscrete, cfg, backend="numba")
```

or via the `TWPA_BACKEND` environment variable, which is used whenever
`backend` is left as `None` (the default is `"numpy"`).

## Dashboard

{py:class}`~dashboard.Dashboard` lets you inspect one or more completed runs
in an interactive Streamlit viewer without re-running any simulation:

```python
from dashboard import Dashboard

Dashboard([S1, S2], freqs=[cfg1.freqs, cfg2.freqs],
          labels=["eps=0.05", "eps=0.10"]).run()
```

## Examples

`src/examples/` has runnable scripts exercising most of the library:
dispersion-relation comparisons, single- vs multi-pump sweeps, adiabatic
pump calibration, and numerical stability checks. `src/main.py` is a worked
end-to-end entry point.
